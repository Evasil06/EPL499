## Required models and evaluation
- Independently fit each of A/B/C using supplied `train.csv`; supplied labeled `test.csv` is validation. No external training data or pretrained Word2Vec. Do not resplit for core evaluation, drop/rebalance rows, or change labels/order. Fit all learned representations, vocabulary/IDF, embeddings, feature selection, scaling and classifiers exclusively on training data (within each training fold if doing CV). Predict with frozen state; never fit during prediction.
- Exact baseline: `CountVectorizer(max_features=10000, min_df=5)` + `MultinomialNB(alpha=1.0)`, all other defaults, raw text without additional preprocessing. BoW+LR and TF-IDF+LR retain max_features=10000 and min_df=5. Word2Vec+LR trains a fresh embedding model per challenge; engineered features+LR uses at least ten justified features. Report classification report and macro-F1 for all 15 model/challenge combinations.
- Member 2: use Lab 8's training and mean-vector pattern as the starting point. Use the shared LR factory rather than Lab 8's Random Forest; handle empty/all-OOV documents without dropping rows; the group suggests a fixed-size zero vector (adaptation, not lab code). Document preprocessing and parameters; run at least one controlled comparison using fresh models. Prefer the Lab 8 100-vs-300 dimensional comparison. CBOW is described but not trained; min_count=2, seed=42 and workers=1 are group settings, not lab examples. No pretrained embeddings in the required model.

Store fitted state per instance; no model-level CSV loading or import-time execution; no input mutation. Respect existing filenames, registry, shared loader/evaluator and experiment hooks.
- Use `config.make_logistic_regression()` without overrides for core LR and `SEED` from config, per group agreement. Honor pinned environment after verifying files. Do not modify shared infrastructure, dependency versions, registry or output formats without group approval. Extra variants are separately named.
- Never fabricate scores, errors, reviews or datasets; the assignment's expected baseline scores are reference values only. Synthetic smoke tests are not real experiments. Analyze at least five actual wrong predictions per member, review another member's code, and document contributions. Explain every important decision, including what the student could change and why, in terms they can defend orally. Flag missing inputs, compatibility issues, uncertainty and any proposed shared changes.
